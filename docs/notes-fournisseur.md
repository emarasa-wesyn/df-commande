# Notes : fournisseur Matériaux Rivière

Notes transmises par le service achats de Delmas & Fournier pour l’intégration des tarifs de Matériaux Rivière (fournisseur fictif).

## Codes tarifaires

| Code | Signification |
|---|---|
| `PUB` | Prix public, sans remise |
| `NEG` | Prix négocié annuel, révisé chaque 1er janvier |
| `PROMO` | Prix promotionnel, valable jusqu’à la date indiquée dans le fichier |

## Fréquence des mises à jour

- Fichier complet chaque lundi à 6 h.
- Fichier différentiel les autres jours ouvrés, uniquement les références modifiées.
